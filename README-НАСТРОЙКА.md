## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Сам сайт |

## 1. Заменить заглушки

Найдите и замените во всём `index.html` (Ctrl+H в любом редакторе):

- `+7 (999) 000-00-00` → ваш телефон в красивом виде
- `79990000000` → тот же номер только цифрами (встречается в ссылках tel:, WhatsApp и разметке Schema.org)
- `https://t.me/placeholder` → ваш Telegram (например `https://t.me/almazprofibur`)
- `ОГРНИП: 326770000000000`, `ИНН: 770000000000` → реквизиты. Выберите одно: «ИП Фамилия И.О.» или «ООО», сейчас написано «ИП / ООО»
- В окне «Согласие на обработку ПДн»: адрес оператора (`___`) и e-mail для отзыва согласия (`___@almazprofibur.ru`)
- Если домен не `.ru`, замените `almazprofibur.ru` везде, включая `robots.txt` и `sitemap.xml`

## 2. Битрикс24

**Заявки с формы.** В Битрикс24 откройте «Разработчикам → Другое → Входящий вебхук», права только **CRM**. Адрес вставьте в `send.php` → `B24_WEBHOOK`. При желании там же укажите `ASSIGNED_BY_ID`, то есть ID сотрудника, на которого падают заявки.

В CRM будут приходить два вида лидов:
- **«Сайт: …»**: заявка на звонок с именем, телефоном, расчётом калькулятора, UTM-метками и отметкой о согласии на обработку ПДн.
- **«Мессенджер: WhatsApp из калькулятора»**: клиент посчитал стоимость и ушёл писать в WhatsApp. Контактов в этом лиде нет, но видно, что он считал и на какую сумму. Когда клиент напишет, объедините лиды.

**Виджет (чат, обратный звонок).** Откройте «CRM → Виджет на сайт → Код для сайта» и скопируйте ссылку `https://cdn-ru.bitrix24.ru/…/loader_….js`. Вставьте её в конец `index.html`, в строку «ВСТАВЬТЕ СЮДА ССЫЛКУ».

**Советы.**
- Подключите WhatsApp и Telegram к **Открытым линиям** Битрикс24, тогда переписка с клиентами тоже будет храниться в CRM.
- **Коллтрекинг** (CRM → Аналитика → Коллтрекинг) покажет, с какой рекламы пришёл звонок. Он работает через виджет и подменяет номер на сайте автоматически.

## 3. Яндекс Метрика

1. Создайте счётчик на metrika.yandex.ru.
2. В `index.html` найдите `const METRIKA_ID = 0;` и впишите номер счётчика.
3. В Метрике добавьте цели типа «JavaScript-событие» с такими идентификаторами:

| Идентификатор | Когда срабатывает |
|---|---|
| `form_submit` | Заявка успешно отправлена (главная цель) |
| `form_open` | Открыли форму заявки |
| `phone_click` | Нажали на телефон |
| `whatsapp_click` | Перешли в WhatsApp |
| `telegram_click` | Перешли в Telegram |
| `calc_whatsapp` | Отправили расчёт калькулятора в WhatsApp |
| `calc_used` | Начали пользоваться калькулятором |

Метрика запускается только после того, как посетитель нажмёт «Принять» в баннере о cookies. Так безопаснее с точки зрения закона, но часть статистики теряется: посетители, которые не нажали кнопку, в Метрику не попадут. Если хотите считать всех, это меняется одной строкой.

## 4. Шрифт

Скачайте Inter на https://rsms.me/inter/ (кнопка Download). В архиве найдите `InterVariable.woff2` и положите его в папку `fonts/` рядом с `index.html`.

Раньше шрифт грузился с Google, и IP посетителей уходили на зарубежные серверы. Если файл не положить, сайт покажет системный шрифт и ничего не сломается.

## 5. Юридическое (152-ФЗ)

Что уже сделано в коде:
- отдельный текст согласия на обработку ПДн;
- неотмеченный чекбокс согласия, без которого заявка не отправится;

Что нужно сделать вам:
- Подать **уведомление об обработке ПДн в Роскомнадзор** (pd.rkn.gov.ru), если ещё не подавали.
- Показать тексты политики и согласия юристу. Они типовые.

## 6. Ускорение сайта (желательно)

Сейчас Tailwind подключён через CDN. Это удобно для разработки, но на мобильных сайт из-за этого грузится медленнее. Чтобы собрать лёгкий CSS-файл, нужен установленный Node.js:

```
npx tailwindcss@3 -i input.css -o styles.css --minify
```

После сборки в `index.html` удалите два блока: строку `<script src="https://cdn.tailwindcss.com"></script>` и следующий за ней `<script>` с `tailwind.config`. Вместо них вставьте:

```html
<link rel="stylesheet" href="styles.css">
```

Пересобирать CSS нужно после каждой правки классов в HTML.

## 7. Что сделать вне кода

- **Реальные фото и видео с объектов** вместо иллюстраций: керн, ровное отверстие, чистый пол после работы. Сейчас на сайте стоят рисунки `images/photo-1.webp` … `photo-9.webp`. Чтобы поставить фото, сохраните его в WebP шириной до 1600 px и положите в `images/` под тем же именем. Затем в `index.html` поправьте у этой картинки `alt`: уберите слово «Иллюстрация» и опишите фото. Пропорции: `photo-1` — 4:3, `photo-2` и `photo-3` — 2:1, снятые с одной точки (слайдер «До/После»), остальные — 2:1.
- **Карточка в Яндекс Бизнесе** и отзывы на Картах.
- **Блок реальных отзывов и объектов** на сайте (ЖК или район, диаметры, цена).
- Позже, для SEO: **отдельные страницы** под основные услуги и районы.
